> My personal **portfolio website** — a multi-page static site built with HTML, CSS, SCSS, and JavaScript, hosted on GitHub Pages.

🌐 **Live site:** https://kuldeep-pal.site/

## Overview

This is the source for my portfolio: a clean, responsive site showcasing my work, background, and ways to get in touch. It’s built with vanilla web technologies (no heavy framework) and organized into focused pages.

## Pages

- 🏠 **Home** (`index.html`) — intro & highlights
- 👤 **About** (`about.html`) — background & skills
- 💼 **Portfolio** (`portfolio.html`) — selected projects
- 📝 **Blog** (`blog.html` / `blog-single.html`) — articles
- ✉️ **Contact** (`contact.html`) — get in touch

## Tech Stack

| Area | Technology |
|------|-----------|
| Markup | HTML5 |
| Styling | CSS3 + SCSS (`scss/` sources) |
| Interactivity | Vanilla JavaScript (`js/`) |
| Assets | Custom plugins & images |
| Hosting | GitHub Pages |

## Project Structure

```
├── index.html          # Home
├── about.html          # About
├── portfolio.html      # Projects
├── blog.html           # Blog listing
├── blog-single.html    # Single blog post
├── contact.html        # Contact
├── css/                # Compiled styles
├── scss/               # SCSS sources
├── js/                 # Scripts
├── plugins/            # Third-party plugins
└── images/             # Assets
```

## Run Locally

Just open `index.html`, or serve the folder:

```bash
python3 -m http.server 8000
# visit http://localhost:8000
```
